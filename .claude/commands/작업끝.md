## 1. 공부정리

`CLAUDE.md`의 "학습 기록 — 공부정리 트리거" 섹션 형식 그대로, 이번 세션(오늘 대화)에서 실제로 한 작업을 `docs/study.md`에 새 날짜 섹션으로 이어붙이세요. 기존 기록은 절대 덮어쓰지 않습니다. 형식: 오늘 한 일 요약 → 새로 나온 개념 쉬운 설명(표) → 확정한 결정 목록 → 왜 그렇게 했는지 이유. 대상 독자는 비개발자 학습자.

## 2. 문서 최신화

- `docs/project-spec.md` 8-1 로드맵 표의 "상태" 컬럼이 오늘 진행 상황과 실제로 맞는지 확인하고 필요하면 갱신
- `CLAUDE.md`의 "현재 진행 상황" 섹션을 오늘 날짜 기준으로 갱신 — 특히 아래를 꼭 포함:
  - 오늘 새로 완료/진행한 것 요약 (이미 세션 중에 갱신해온 내용이 있으면 중복 없이 정리)
  - **다음 세션(다른 터미널에서 새로 시작해도)에서 바로 이어갈 수 있게, 정확히 어디서부터 시작하면 되는지 한 줄로 명시**
  - Supabase에 아직 실행 안 한 마이그레이션 파일이 있으면 파일명으로 목록 나열
  - 사용자가 직접 확인/테스트해야 할 게 남아있으면 명시

## 3. Git 커밋

- `git status`, `git diff`로 이번 세션 변경사항 전체 확인
- `.env` 등 민감 파일이 스테이징되지 않는지 확인
- 관련된 파일들을 의미 단위로 묶어 커밋 메시지 작성 (한국어 설명 가능, 컨벤셔널 커밋 스타일 `feat:`/`fix:`/`docs:` 등 접두어)
- 커밋 메시지 끝에 `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>` 추가

## 4. Git 푸시

- `git push`로 원격(origin/main)에 반영
- "작업끝" 자체가 커밋/푸시 요청이므로, 이 단계는 매번 다시 승인 여부를 묻지 않고 진행합니다

아래 내용을 한국어로 짧게 정리해서 사용자에게 보고:
