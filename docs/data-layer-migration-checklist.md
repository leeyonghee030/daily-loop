# 데이터 레이어 마이그레이션 체크리스트 (react-query 도입)

## 왜 이 문서가 있는가

지금까지 각 화면(오늘/캘린더/통계 탭 등)이 "포커스될 때마다 서버에서 다시 불러오기"를 각자 손으로
`useEffect`/`useFocusEffect`를 조합해서 구현해왔음. 이 방식이 화면마다 조금씩 다르게 짜여서
stale closure, 중복 요청, 과도한 재렌더(깜빡임) 같은 버그가 반복적으로 나왔음(2026-08-29~31 세션).

근본 원인은 도메인 모델(테이블 관계)이 아니라 "데이터를 불러오고 캐시하는 방식"이 표준화되지 않은
것이라 판단, `@tanstack/react-query`로 이 레이어를 표준화하기로 결정함(2026-08-31).

**이 문서의 용도**: 마이그레이션 전 지금 동작하는 기능을 빠짐없이 적어두고, 화면을 하나씩
react-query로 옮길 때마다 이 목록과 대조해서 기능이 안 없어졌는지 확인하는 회귀 체크리스트.
각 항목 앞 체크박스는 "새 구조에서도 확인 완료"를 의미함 — 마이그레이션 진행하면서 갱신할 것.

## 화면 간 캐시 공유 쿼리 키 (참고용)

같은 키를 쓰는 화면들은 한쪽에서 체크/수정하면 react-query 캐시가 자동으로 공유돼서
다른 화면도 다음에 그 쿼리를 다시 보는 시점에 최신 값으로 보임. 새 화면을 추가할 때
이미 있는 키를 재사용할지 먼저 확인할 것.

- `['slots', userId]` — 오늘 탭, 캘린더(알림 동기화용), 설정, 즐겨찾기 폼, 모음집 폼, 루틴 폼
- `['favorites', userId]` — 즐겨찾기 목록 화면, 루틴 폼
- `['stats', userId]` — 오늘 탭, 캘린더, 통계 탭 (역대 최고 스트릭 포함)
- `['streak-configs']` — 오늘 탭, 통계 탭 (1시간 캐시, 자주 안 바뀌는 참조 데이터)
- `['presets', userId]` — 모음집 목록 화면, 내 루틴 화면
- `['llm-quota', userId]` — 오늘 탭, 말로 루틴 추가 화면(호출 성공 시 로컬로 즉시 갱신)
- `['video', id]` — 루틴 폼(연결된 영상 미리보기), 영상 재생 화면

## 가벼운 손질(light-touch)만 한 화면들

`favorite-form.tsx`/`preset-form.tsx`/`routine-form.tsx`/`diary-form.tsx`는 폼 화면 특성상
`useRefetchOnFocus`를 안 붙였음(수정 중인 입력값을 포커스마다 덮어쓰면 안 되므로) — 읽기 전용
참조 데이터(`slots`/`favorites`)만 공유 쿼리로 불러오고, 폼 로컬 상태는 그 데이터가 도착했을 때
한 번 `useEffect`로 시딩하는 방식.
