# 마케팅 전략 — 인스타그램 릴스 + 스레드 (2026-09-15 시작)

## 배경 / 원래 고민

- 오늘부터 인스타그램 릴스 + 스레드로 Daily Loop 마케팅을 시작해보고 싶음
- 방향: **릴스 후킹으로 낯선 사람(콜드 트래픽) 모으기 + 스레드 병행**
- 걱정했던 부분:
  - 얼굴은 안 나왔으면 좋겠음
  - 개발 과정(빌드로그) 릴스만 계속 올리면 사람이 안 모일 것 같음 → 어떻게 하는 게 좋을지

## 핵심 결론: 콜드 트래픽과 웜 트래픽의 역할을 분리한다

원래 생각한 방향(릴스=후킹, 스레드 병행)은 맞는 방향이었고, 여기에 **"프로필 고정 게시물"의 역할**을 명확히 구분하면 구조가 완성됨:

| 구간 | 트래픽 종류 | 역할 |
| --- | --- | --- |
| 릴스 | 콜드 트래픽 (안 팔로우한 사람에게 알고리즘이 뿌리는 콘텐츠) | **후킹**으로 낯선 사람 관심 끌기 |
| 프로필 고정 (상단 3개) | 웜 트래픽 (이미 궁금해서 프로필까지 들어온 사람) | 깔끔한 **기능 소개**로 확신 주기 |

**왜 이렇게 나눠야 하는가**: 릴스는 안 팔로우한 사람에게 알고리즘이 노출시키는 콘텐츠라, 거기서 "이 앱이 뭔지" 설명부터 하면 3초 안에 이탈함. 반대로 프로필까지 들어온 사람은 이미 궁금해서 클릭한 것이므로, 그 단계에서는 오히려 정리된 기능 소개가 "오 깔끔하네, 써볼까"로 전환시키는 역할을 함. **콜드 트래픽에 기능 자랑, 웜 트래픽에 후킹만** 하는 식으로 반대가 되면 둘 다 효과가 떨어짐.

→ "개발 릴스만 올리면 안 모일 것 같다"는 걱정은, 릴스를 한 가지 톤(개발 과정)으로만 채우지 않고 아래 6가지 각도를 로테이션하면 해결됨.

## 릴스 "다각면 후킹" 각도 로테이션

매번 같은 톤이면 금방 질리므로, 아래 각도를 돌아가며 사용:

1. **공감/문제제기형**: 예) "루틴 3일 만에 무너진 이유 (feat. 앱 15개 지운 사람)"
2. **논쟁/의견형**: 예) "미라클모닝 챌린지, 사실 이 방식 틀렸다고 생각함" → 마지막에 자연스럽게 앱 연결
3. **비포애프터형**: 복잡한 다른 앱 화면들 vs Daily Loop 한 화면 비교
4. **실패담/스토리텔링형**: "나 원래 루틴 3일 천하였는데" 서사 구조
5. **정보/꿀팁형**: 루틴 관련 팁을 주다가 마지막에 "이런 거 정리하기 좋은 앱"으로 자연스럽게 연결
6. **트렌드 밈/챌린지 활용형**: 유행하는 릴스 포맷/오디오에 앱 내용을 얹기

→ 이 6개를 로테이션 돌리면 "매일 뭘 만들지" 고민이 크게 줄어듦. 얼굴 노출 없이도 화면 녹화 + 자막 + 트렌드 오디오로 대부분 소화 가능한 각도들.

## 인스타 프로필 고정 게시물 (상단 3개) 구성 추천

인스타는 프로필 상단에 고정 게시물을 3개까지 걸 수 있음:

1. **기능 한눈에 보기 카드뉴스(캐러셀)**: 화면 캡처 4~5장, 텍스트는 최소화해서 슬라이드당 하나씩만 (예: "미니멀 UI" / "사진일기" / "영상 연결")
2. **브랜드 스토리형**: "왜 이 앱을 만들었는지"를 짧고 공감 가는 서사로 — 신뢰 쌓기용
3. **후기/비포애프터 또는 실제 사용 화면**: 있으면 신뢰도가 확 올라감. 아직 없으면 위 2개로 먼저 시작해도 충분

**영상보다 카드뉴스(스크린샷 + 최소 텍스트) 형태가 고정용으로 더 적합** — 프로필에 들어온 사람이 스르륵 넘기면서 "아 이런 기능들 있구나"를 빠르게 파악하는 게 목적이기 때문.

## 운영 팁 — 스레드로 먼저 검증

스레드는 텍스트만 쓰면 되므로, **릴스로 만들기 전에 훅 문장을 스레드에 먼저 던져보고 반응 좋은 것만 릴스로 발전**시키는 식으로 운영하면:

- "될 만한 소재"만 골라서 릴스로 제작 → 제작 시간 절약
- 반응 검증된 소재라 성공률도 올라감

## 2주 릴스 구조 기획

### 같은 내용을 반복해도 되는 이유 (사용자 판단 = 맞음)

릴스는 대부분 **안 팔로우한 사람**에게 알고리즘이 개별로 노출시키는 콘텐츠라서, "내 릴스를 처음부터 끝까지 다 보는 사람"은 거의 없다고 가정하는 게 맞음. 그래서:

- 같은 **핵심 메시지(기능/장점)** 를 여러 번 다뤄도 괜찮음 — 어차피 한 사람이 두 개를 연달아 볼 확률이 낮음
- 대신 매번 **훅 문장 / 구조 / 각도**를 다르게 해서, 알고리즘이 "비슷한 콘텐츠 반복"으로 판단해 노출을 줄이는 걸 피함
- → 그래서 아래 계획은 "핵심 메시지 4개(기둥)"를 정해두고, 14일 동안 이 기둥들을 6가지 훅 유형으로 돌려가며 다른 순서/다른 각도로 반복하는 구조

### 훅(첫 3초) 쓰는 원칙

1. **정보 격차 또는 감정 반응을 3초 안에 만든다** — "궁금해서 못 넘기게" (호기심) 또는 "저거 내 얘기잖아" (공감/찔림)
2. **광고 냄새를 뺀다** — 훅 문장에 앱 이름·"추천"·"소개" 같은 단어를 넣지 않음. 일반인의 하소연/경험담처럼 시작
3. **"이 앱 좋아요"가 아니라 "이 문제를 이렇게 풀었다"는 서사로** 기능이 자연스럽게 등장하게 함
4. **CTA는 가볍게** — "링크 있음" 정도로 끝, 강요하지 않기

| 기둥 | 내용 | 강점 |

## Day 1 릴스 대본 — 공감/문제제기형

**훅**: "루틴 3일 만에 무너진 이유 (feat. 앱 15개 지운 사람)"
**목표**: 얼굴 노출 없이 화면 녹화 + 자막만으로 제작. 15~20초 분량.
**필요한 촬영**: (1) 폰 홈화면에서 루틴/생산성 앱 여러 개를 스와이프하며 보여주는 화면 녹화 5초, (2) Daily Loop 오늘 탭 화면 녹화 5초. 얼굴·목소리 없이 자막(캡션)으로만 진행 가능.

| 구간 | 시간 | 화면 | 자막(온스크린 텍스트) |
| --- | --- | --- | --- |
| 훅 | 0–3초 | 검은 배경 또는 폰 홈화면 정지 | **"루틴 앱 15개 지워봄"** (큰 흰 글씨, 화면 중앙) |
| 문제 제기 | 3–7초 | 홈화면에서 앱 여러 개 스와이프하며 보여주기 | "다 하나씩은 좋았는데" → "결국 3일 만에 안 열게 됨" (순차 등장) |
| 공감 포인트 | 7–11초 | 화면 전환(빠르게 앱 아이콘들 클로즈업 컷) | "기능이 많아서가 아니라" → "매번 앱을 여는 것 자체가 일이라서" |
| 전환(터닝포인트) | 11–13초 | 검은 화면 1초 페이드 | "그래서 그냥 하나만 남겼음" |
| 리빌(앱 소개) | 13–18초 | Daily Loop 오늘 탭 화면 녹화(체크 누르는 손가락 클로즈업 or 화면만) | "루틴 체크 + 캘린더 + 일기, 한 화면" |
| CTA | 18–20초 | 앱 로고/아이콘 정지 화면 | "프로필 링크 👆" |

**추천 오디오**: 잔잔하고 약간 긴장감 있는 트렌드 배경음(감성 로파이 계열) — 인스타 릴스 오디오 검색에서 "감성", "잔잔한 브금", "lofi" 태그로 최근 사용량 높은 것 아무거나 선택. 목소리 녹음 없이 자막만으로 완결되는 구성이라 오디오는 분위기용으로만 깔면 됨.

**캡션(게시물 본문) 예시**:
> 루틴 앱 15개 지우고 결국 하나만 남겼습니다
> 앱이 많은 게 문제가 아니라, 매번 여는 것 자체가 귀찮았던 거더라구요
> 체크 + 캘린더 + 일기까지 한 화면에 — 프로필 링크에 있어요
> #루틴 #루틴앱 #미라클모닝 #생산성 #자기관리

**해시태그 전략**: 너무 좁은(#dailyloop 같은 자체 브랜드) 태그보다 검색량 있는 일반 태그(#루틴, #루틴앱, #자기관리, #갓생) 위주로 5~8개.

**제작 순서 요약**:
1. 폰 화면 녹화 켜고 루틴/생산성 앱 몇 개(캘린더, 투두, 메모 등) 스와이프하며 5초 녹화
2. Daily Loop 오늘 탭 열어서 체크하는 모습 5초 녹화
3. CapCut/VLLO 등 무료 편집 앱에서 위 표의 자막을 타이밍 맞춰 얹기(폰트는 굵고 큰 것 추천)
4. 배경음 추가 → 내보내기 → 캡션 붙여서 게시
