# Daily Loop — 유저플로우

> `project-spec.md`에서 확정된 화면/기능을 실제 사용자 이동 순서로 정리한 문서. 화면 번호(4-N)는 `project-spec.md`의 해당 섹션을 가리킴.

---

## 0. 전체 구조 (사이트맵)

```
스플래시
  └─ (미로그인) 로그인 화면
        ├─ 구글 로그인
        └─ 카카오 로그인
              └─ (최초 1회) 온보딩
                    └─ 하단 탭 3개
  └─ (로그인 상태 유지) 하단 탭 3개
        ├─ 오늘 탭 (홈, 4-1)
        │     ├─ 루틴 추가 (수동, 4-9 / 자연어, 4-8)
        │     ├─ 영상 재생 (4-10)
        │     └─ 일기 쓰기 (4-5)
        ├─ 캘린더 탭 (4-2)
        │     └─ 날짜 상세 (체크리스트 + 일기)
        └─ 통계 탭 (4-3)
  └─ 설정 (진입 경로: 오늘 탭 상단 아이콘 등 — 화면 위치 미정, 12번 참고)
        ├─ 슬롯 시간 조정 + 슬롯별 알림 on/off (4-7)
        ├─ 계정 (로그아웃, 탈퇴)
        └─ 구독 상태 (2차 버전 이후)
```

---

## 1. 온보딩 → 첫 로그인

```
① 스플래시 (로고)
② 로그인 화면 — "구글로 시작하기" / "카카오로 시작하기" 버튼 2개
③ 소셜 인증 진행 (구글: Firebase 기본 지원 / 카카오: 카카오 SDK → Firebase Custom Token 교환)
④ [신규 유저인 경우만] 온보딩 1~2장
     - 앱 정체성 한 줄 소개: "말하듯 적으면 루틴이 짜여요"
     - 회원가입 시점에 기본 슬롯 4개(아침/점심/저녁/자기전) 자동 생성, 기본 시간값 세팅
⑤ 오늘 탭(홈) 진입 — 루틴이 하나도 없으므로 빈 상태 화면 노출 (8-1 참고)
```

- **재로그인(기존 유저)**: ③ 성공 시 온보딩 없이 바로 오늘 탭으로 이동
- **로그인 실패**: 에러 토스트 "로그인에 실패했어요, 다시 시도해주세요" + 로그인 화면 유지

## 2. 매일 체크 (핵심 루프)

```
① 오늘 탭 진입 — 오늘 날짜 + 시간순 정렬된 루틴 블록 리스트
     (명시 시간 있는 블록은 시각순, 슬롯 배정 블록은 슬롯 위치에 표시,
      같은 시각/슬롯 내에서는 사용자가 지정한 sort_order 순)
② 블록 탭
     ├─ 일반형(체크형) → 체크 버튼 탭 → 즉시 완료 처리, 완료 시각 기록
     ├─ 트래킹형(수치형) → 숫자 입력 UI → 입력 즉시 완료 처리, 입력값 원시 기록
     └─ 영상 연결된 블록 → 재생 아이콘 탭 → 영상 재생 화면(4-10) 이동
③ 필수 블록 미완료 상태로 남아있으면 캘린더에서 오늘 날짜가 빨간색 후보로 표시됨(자정 기준 확정)
④ 하단에서 오늘 완료율 + 스트릭 확인
⑤ (선택) 하단 "일기 쓰기" 카드 탭 → 텍스트 입력 → 저장 (날짜당 1개, 이미 있으면 수정 모드로 열림)
```

- **빈 상태** (루틴이 하나도 없을 때): 리스트 자리에 "아직 루틴이 없어요. 편하게 말하듯 적어보세요 →" + LLM 입력 배너로 자연스럽게 유도
- **당일 리마인더**: 자기전 슬롯 시각에 필수 루틴 미완료가 남아있으면 FCM 푸시 발송 → 탭 시 오늘 탭으로 딥링크 (4-12)

## 3. 루틴 추가 — 수동 (4-9)

```
① 오늘 탭 우측 상단(혹은 리스트 하단) "+ 추가" 버튼
② 루틴 추가/수정 폼
     - 제목 (필수)
     - 시간 (필수: 정확한 시각 입력 OR 슬롯 4개 중 직접 선택 — 자동 배정 없음)
     - 반복 설정 (매일/특정요일/평일만/주말만/1회성)
     - 블록 타입 (일반형/트래킹형) → 트래킹형 선택 시 단위 프리셋 버튼 노출
     - 필수/선택 토글
     - 카테고리 (선택, 6개 중)
     - 영상 연결 (선택) → 4-10 목록을 바텀시트로 열어 선택
     - 알림 on/off (선택, 루틴 단위)
③ "저장" → 오늘 탭 리스트에 즉시 반영
```

- **필수 필드 미입력**: 저장 버튼 비활성 + 미입력 필드 하단에 인라인 에러 문구
- **수정/삭제**: 기존 블록 롱프레스 또는 상세 진입 → 같은 폼 재사용, 삭제는 소프트 삭제(3-2) 처리 후 리스트에서 즉시 사라짐

## 4. 루틴 추가 — 자연어(LLM) (4-8)

```
① 오늘 탭 상단 LLM 입력 배너 탭 (잔여 N/10회 표시)
     - 0/10이면 배너 문구가 "이번 AI 배치 횟수를 모두 사용했어요 →" 로 전환되고
       탭 시 바로 ③(수동 추가 폼)으로 이동 (4-13)
② 텍스트 입력 (바텀시트/풀스크린)
③ 파싱
     ├─ 정규식/키워드 사전 매칭 성공 → "규칙 기반 처리" 배지, 즉시 결과 (LLM 미호출, 횟수 차감 없음)
     └─ 애매한 표현 → "AI가 분석 중..." 로딩 → LLM 호출 (횟수 1 차감)
          └─ [실패 시] 에러 상태 화면 "지금은 AI 배치가 어려워요" + [다시 시도] [직접 추가] (4-13)
④ 미리보기 — 파싱 결과를 루틴 블록 카드(초안)로 표시, 4-9와 동일 폼 컴포넌트로 각 필드 인라인 수정 가능
     - 시간대 키워드/시각이 전혀 없었다면 이 단계에서 슬롯 선택 UI가 노출되고 사용자가 직접 확정
⑤ "이대로 추가" 버튼 탭 → 저장 (자동 저장 없음, 반드시 사용자 확정 필요)
```

- 한 번의 입력으로 루틴 1개만 생성 — 여러 개 추가하려면 ①~⑤ 반복

## 5. 캘린더 조회 (4-2)

```
① 캘린더 탭 — 월 단위 뷰, 날짜별 컬러 코딩
     🟢 완료 / 🟠 일부 완료 / 🔴 필수 루틴 미완료
② 날짜 클릭 → 하단에 해당 날짜 체크리스트 + 그날 작성한 일기 펼쳐짐
     - **과거 날짜의 체크리스트는 읽기 전용 (신규 확정)** — 체크/해제 등 사후 수정 불가. 기록의 신뢰도와 스트릭/통계 계산을 단순하게 유지하기 위한 결정
     - 일기는 과거 날짜라도 자유롭게 수정 가능 (신규 확정) — 루틴 체크와 달리 통계/스트릭 계산에 영향을 주지 않으므로 소급 수정 허용
③ 월 이동 (좌우 스와이프 또는 화살표)
```

- **미래 날짜 클릭**: 체크리스트는 그날 적용될 예정 루틴 미리보기로 표시(완료 불가), 일기는 작성 불가

## 6. 설정 (신규 확정)

```
① 진입 위치: 오늘/캘린더/통계 3개 탭 모두 공통 상단 헤더에 설정 아이콘 고정 노출
     (탭을 이동해도 항상 같은 자리에서 접근 가능 — 특정 탭에 종속시키지 않음)
② 설정 화면 (단일 리스트형, 신규 확정)
     - 슬롯 4개(아침/점심/저녁/자기전) 각각: 시작/종료 시각 수정 + 알림 on/off 토글
     - 계정: 로그아웃 / 탈퇴 (탈퇴 시 소프트 삭제 처리)
     - 앱 정보: 버전 등
     - (2차 버전) 구독 상태/결제 관리
```

- 항목이 적어서 탭/섹션 분리 없이 세로로 나열하는 단일 화면. 항목이 늘어나면 그때 분리 검토
- UI 작업 시 헤더(설정 아이콘) 컴포넌트를 3개 탭 공통으로 재사용

## 7. 알림 수신 후 흐름 (FCM, 4-12)

```
① 블록 알림 수신 (슬롯 시각) → 탭 → 오늘 탭 딥링크, 해당 슬롯 위치로 스크롤(선택)
② 리마인더 알림 수신 (자기전 슬롯 시각, 필수 미완료 있을 때만) → 탭 → 오늘 탭 딥링크
```

- 앱이 완전 종료 상태여도 FCM은 OS 레벨에서 수신 → 탭하면 콜드 스타트 후 동일하게 오늘 탭으로 이동

## 8. 오류 / 빈 상태 화면 정리

| 상황 | 화면 |
|---|---|
| 루틴 0개 (신규 유저) | 오늘 탭 빈 상태 + LLM 입력 유도 문구 |
| LLM 횟수 소진 | 배너 문구 전환 + 탭 시 수동 추가로 즉시 이동 (4-13) |
| LLM 호출 실패 | 에러 카드 + [다시 시도] [직접 추가] (4-13) |
| 로그인 실패 | 토스트 + 로그인 화면 유지 |
| 네트워크 끊김 (일반) | 화면 상단 배너 "오프라인 상태예요" (신규 확정) — 루틴 체크/저장 등 액션은 그대로 허용, 로컬 반영 후 온라인 복귀 시 자동 동기화 |
| 필수 필드 미입력 (루틴 폼) | 인라인 에러 문구, 저장 버튼 비활성 |
| 통계 탭 (완료 기록 없음, 신규 유저) | 심플 텍스트 문구만: "아직 기록이 없어요, 루틴을 먼저 체크해보세요" (신규 확정, 별도 일러스트 없음) |
| 영상 큐레이션 카테고리 (해당 카테고리 영상 없음) | 심플 텍스트 문구만: "준비 중입니다" (신규 확정, 별도 일러스트 없음) |
